# Social Media Impact on Students' Lives – SQL Data Analysis

## Project Overview
I used a dataset about students' social media habit to  explore and find  some interesting patterns in the data.

I wanted to find out which platforms students use most, how much time they spend on social media, and whether late-night usage is related to their sleeping habits and academic performance.

The analysis focuses on social media platform preferences, daily usage, sleep patterns, and academic performance.

## Tools Used
- MySQL
- SQL

## Dataset
The original dataset contains 4,500 student records and 16 columns.

A total of 4,369 records were successfully imported into MySQL and used for this analysis. The remaining 131 records were not included in the analysis.

## Analysis Questions

1. Which social media platform is the most popular among students?
2. Which platform has the highest average daily usage?
3. Is late-night social media usage associated with sleep duration and sleep quality?
4. Which academic level has the highest average GPA?

## Key Findings

- Instagram was the most commonly reported primary platform, with 1,408 students.
- Snapchat had the highest average daily usage at 5.42 hours.
- Students reporting late-night usage slept less on average and reported lower sleep quality.
- Postgraduate students had the highest average GPA at 3.47.

## Limitations
This analysis uses descriptive statistics and identifies patterns in the dataset. It does not establish cause-and-effect relationships.

The analysis is based on 4,369 imported records rather than the full 4,500 records.

## Conclusion
This project demonstrates the use of SQL for data exploration, aggregation, and analysis. It provides insights into students' social media habits, sleep patterns, and academic performance.
